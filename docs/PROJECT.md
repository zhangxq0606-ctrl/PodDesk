# podcast-desk

## 价值与对象

- 服务对象：船长本人，以及具备一定电脑操作能力、重度使用 AI 工具与知识管理（PKM）的独立开发者、内容创作者与大学生同路人；远期保留向更广泛同类普通用户推广的能力。
- 核心问题：纯英文音频播客听不懂（现有浏览器视频翻译插件不覆盖纯音频场景）；无论中英文音视频播客，均缺少顺手的「带播放上下文的在场感 AI 问答」以及「低摩擦的知识吸收与 Markdown 导出沉淀」。
- 长期目标：打造一套低成本、零海外服务器依赖、可从本地轻量网页工作台平滑演进至大众分发版的跨媒介播客/视频消化与 AI 知识沉淀工作台。
- 第一阶段承诺结果：跑通脱壳后的「本地 Rust 轻量后端 + 浏览器全屏工作台」，复用 SubCast 的核心取稿、双语对照与本机 5 种 CLI Agent / 直连大模型高效嵌入能力，实现中英文音视频播客从「粘贴链接拿稿」到「双语阅读 + 带时间戳在场感 AI 问答 + 基础文本/对话导出」的完整可用闭环。

## 核心使用场景

1. **启动与入口**：用户在本机启动轻量后端服务，电脑默认浏览器自动打开 `http://localhost:<port>` 全屏工作台（无需账号注册、无需安装重型签名客户端）。
2. **添加内容**：用户粘贴 YouTube 频道/单集视频链接、Apple Podcasts / 任意播客 RSS、小宇宙链接，或直接导入本地音视频文件、粘贴纯文本/导入 `.srt`/`.vtt` 字幕文件；列表支持单集直开（不强制先订阅频道）。
3. **获取文字稿与双语对照**：系统按优先级获取字幕——先取官方字幕（YouTube 字幕或 RSS `<podcast:transcript>`），无字幕时由用户选择走外调 `Qwen3-ASR` 本机离线转写（音频不出本机）或自带 Key 的云端语音转文字；翻译采用大模型术语表感知分批精译（通过本机已登录 CLI Agent 或直连大模型实现，已于 `v0.2.1` 剥离谷歌免费翻译）。
4. **边听/看边在场感问答**：音频/视频播放器与双语字幕同步高亮；用户在右侧面板直接调用本机已登录的 CLI Agent（Claude Code / Codex / Antigravity / Kimi Code / OpenCode）或 DeepSeek 等国内直连模型提问，回答中的 `[mm:ss]` 时间戳可点击精准回跳播放位置。
5. **离开与基础留存**：单集订阅、字幕、译文、播放进度与多轮问答全部保存在本地 SQLite，关闭浏览器后下次打开原位续接；首版支持原版基础对话复制与整段 Markdown/文本导出。

## 不可替代体验与约束

- **完整独立工作台体验**：不以寄生在网页边角的浏览器插件形态交付，必须具备独立全屏的音视频播放、双语对照与 AI 问答工作台。
- **高效免折腾接入 AI Agent**：延续原版自动探测并保活本机 CLI Agent 与国内直连大模型的能力，不在首版强迫用户自建复杂推理后端。
- **隐私与零云端成本底线**：永不在用户未主动选择时将音频上传云端；外网抓源走用户本机系统代理，首版零海外服务器、零持续云端算力账单。
- **编译与运维轻量化**：首版不引入需要 `CMake`/`LLVM` 编译链的内置 `whisper-rs`，确保本机（Windows + Git/Node/Rust/VS BuildTools）与后续维护轻量可控。

## 现有解法与项目差异

| 现有方案 | 强项 | 相对本项目核心缺口 |
|---|---|---|
| **BibiGPT** | 跨平台链接一键快摘要 | 闭源收费、偏快餐摘要，缺沉浸式双语精读与本地 Agent 深度对话流 |
| **Podwise** | 播客思维导图与笔记导出生态强 | 付费订阅制，不覆盖视频源，难以结合个人私有 Agent 定制沉淀 |
| **NotebookLM** | 多源资料库综合问答与引用准确 | 不支持播客 RSS 播放与双语高亮字幕同步 |
| **Obsidian Web Clipper / PodNotes** | 开源免费、直连 Obsidian | 属单点工具，缺术语表双语翻译与统一在场感问答工作流 |
| **上游 SubCast（`v0.2.8`–`v0.3.2`）** | Rust 抓源/解码/Agent 保活与 AI 翻译工程极其扎实 | 绑定 Tauri 桌面分发（Mac `$99/年` 公证、Windows SmartScreen）、强绑作者私域站点（`*.qiaomu.ai`），且 `v0.3.2` 急速膨胀出视频切片剪辑与中文配音跟读等重功能 |
| **HackerTube** | 反算法精选发现、无账号本地状态、对 Agent 友好 | 定位为“找什么看”的发现站，不含音视频取稿、离线转写与双语消化能力 |

**本项目差异**：裁剪上游 SubCast 的重桌面壳、作者私域生态与冗余二创功能，改造成「本地 Rust 稳态服务 + 浏览器工作台」，先做稳跨媒介取稿与高效 AI Agent 在场感问答，再于后续阶段叠加差异化的「AI 结合对话上下文收束导出 Markdown」工作流。

## 第一阶段范围

### 包含

- **底层形态与首条验证切片**：
  - 脱壳后的独立本地 Rust HTTP/SSE 服务 + React/TS 浏览器前端工作台；
  - **第一条端到端最小垂直切片**：启动本地 Rust 服务并在浏览器打开 `localhost` 界面 → 粘贴一条 YouTube 或播客单集链接拉取官方字幕 → 调通一个本机 CLI Agent 或国内直连大模型完成一次带 `[mm:ss]` 时间戳跳转的在场感问答。
- **多源输入与播放**：YouTube（含频道/单集及禁嵌视频直链回退）、播客 RSS / Apple Podcasts 查找、小宇宙（采用上游 `v0.3.2` 修复后的解析逻辑）、单链接直开、本地音视频文件导入，以及**纯文本 / `.srt` / `.vtt` 字幕文件兜底导入**（零反爬成本覆盖 B 站、课程录播、会议纪要等平台外内容）。
- **文字稿与翻译管线**：
  - 官方字幕（YouTube 字幕 / `<podcast:transcript>`）→ 外调 `Qwen3-ASR`（`CrispASR` 独立程序）离线转写 → 用户自填 Key 的云端 ASR；
  - 大模型术语表感知分批翻译（支持导读同意后一键联动精译；已于 `v0.2.1` 剥离谷歌免费翻译，不依赖任何第三方翻译中转）。
- **AI 能力与基础导出**：像原版一样高效嵌入 5 种本机 CLI Agent 与 OpenAI/Anthropic 兼容模型；前端预设精简为**高频核心 6～8 家（DeepSeek、硅基流动、OpenRouter、Claude、OpenAI、Gemini、Kimi/通义）+ 本地 Ollama + 通用自定义 OpenAI 兼容**，支持导读、带 `[mm:ss]` 跳转的整稿问答、单集基础对话复制与整段文稿导出（参考上游 `subexport.ts` 段落保留与安全文件名清洗）。
- **网络与风控兜底**：自动继承本机系统/手动代理；针对脱壳后无内置 WebView 的情况，在纯技术层提供按需贴入 `cookies.txt` 给 `yt-dlp` 使用的轻量退路。

### 明确不做

- **首版永久/当前裁剪项**：
  - 内置 `whisper-rs`（剥离以去除 `CMake`/`LLVM` 依赖，中英文由 `Qwen3-ASR` 与云端 ASR 覆盖）；
  - 原作者私有生态（`*.qiaomu.ai` 精读站点、`rss.qiaomu.ai`、`elon.qiaomu.ai` 翻译中转、自有 `yt-dlp` 镜像同步）；
  - 前端 OTA 签名热更新体系（`ota.rs`）与桌面端代码签名公证；
  - 上游 `v0.3.2` 新增的视频高光切片剪辑、封面渲染、中文 AI 配音、跟读打分及 Anki 生词本；
  - 用户账号体系、云端同步与自建海外服务器；
  - 视频模式右侧文字稿字幕 Tab（与视频叠层字幕冗余，已明确否决）及低收益极客零碎增强（`j/k/l` 与 `0–9` 全局音视频快捷键、Show Notes 展示降噪、中段真实画面封面切换）。
- **明确延后至核心工作台跑通后的二期项**：
  - 深度 AI 知识沉淀工作流（结合文稿/划词/多轮问答上下文的一键多视角 Markdown 整理、直写本地 Obsidian 目录）；
  - 轻量本地 MCP Server（复用 `podcast_desk_core` 暴露播客库检索、文稿读取与导读问答能力，供外部 Claude Code / Codex / Cursor / Antigravity 等助手反向调用与沉淀联动）；
  - 共享字幕/导读飞轮服务端上线（保留接口位，待未来推广期出现高频重叠消费后再部署至现有国内 2核2G 服务器）；
  - 订阅清单迁移与分享（按需补充 OPML 订阅导入导出，面向跨机迁移或对外推广期；原独立结构化上下文 JSON 出口由轻量本地 MCP Server 覆盖）。

## 成功标准

1. 本机不安装 `CMake` 与 `LLVM`，可顺利编译并启动本地 Rust 服务，浏览器打开 `localhost` 工作台无报错。
2. 粘贴一条 YouTube 英文视频链接与一条播客/小宇宙链接，均能成功入库、播放并产出可用文字稿（有官方字幕优先直出；无字幕可通过外调 `Qwen3-ASR` 或云端 ASR 转写）。
3. 无需付费海外服务器即可完成中英双语对照（通过本机已登录 CLI Agent 或直连大模型精译），且右侧面板可稳定调用本机已登录 CLI Agent 或直连大模型输出带 `[mm:ss]` 的回答并点击跳转播放。
4. 关闭浏览器后重启服务，订阅列表、字幕、译文、播放进度与对话历史完整保留，且可基础复制/导出对话与整段 Markdown 文稿。
