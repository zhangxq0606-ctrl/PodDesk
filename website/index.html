macOS「已损坏，无法打开 / 移到废纸篓」处理方式
为什么会出现提示？ PodDesk 为开源免费桌面应用，暂未购买 Apple 开发者公证签名；macOS Gatekeeper 默认会拦截从网页下载的未公证应用并误报“已损坏”。
解决方法（仅首次需要）：
1. 打开 PodDesk_0.2.0_aarch64.dmg，将 PodDesk 拖入「应用程序」。
2. 打开 macOS「终端」，粘贴执行下方命令清除隔离属性后即可正常打开：
xattr -dr com.apple.quarantine /Applications/PodDesk.app

常见问题

没有 API Key 能直接用吗？

可以。获取官方字幕、本机离线转写与基础翻译均无需配置 API Key；若本机已登录 Codex、Claude Code、Gemini CLI 等命令行 Agent，在场问答也可直接接入，复用你现有的订阅额度。

访问 YouTube 或使用翻译需要代理吗？

访问 YouTube 与谷歌免费翻译需本机网络可达，PodDesk 会自动沿用你的系统代理，无需单独配置；小宇宙、本地音视频导入及国内直连模型无需代理。

支持 macOS 吗？

支持。现已提供 macOS 11+（Apple Silicon M 系列芯片）原生 .dmg 安装包，本地离线转写自动启用 Metal 加速；Intel Mac 暂可从源码自行构建。
