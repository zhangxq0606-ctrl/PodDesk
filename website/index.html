没有 API Key 能直接用吗？

可以。官方字幕、离线转写与基础翻译开箱即用；本机已登录 Codex、Claude Code 或 Gemini CLI 也可直连问答。

需要代理吗？音频和数据存在哪？

访问 YouTube 自动沿用系统代理；小宇宙、本地音视频与转写全程本机运行，音频与文稿不出设备。

如何更新版本？支持 Intel Mac 吗？

客户端内置新版本检测与更新说明；macOS 安装包提供 Apple Silicon 原生版，Intel Mac 可从源码构建。
